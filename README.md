# zimo-portfolio (Next.js + Tailwind)

## Quick start

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Customize content

Edit:
- `lib/site-data.ts` (name, links, projects, experience, publication)

## Deploy

### Vercel
- Import the repo in Vercel
- Framework preset: Next.js
- Build: `next build` (default)
- Output: (default)

### GitHub Pages?
Next.js needs special setup; Vercel is easiest. If you want GitHub Pages, we can switch to a static export setup.

## Resume file
This template expects a PDF at `public/resume.pdf`.
